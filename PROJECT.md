# Проект 03 — Сайт города Minecraft

## Кратко
- Название: Smertnik Squad | Hamburg | SGRB (рабочее; проверь написание и расшифровку SGRB)
- Тип проекта: сайт и игровая айдентика
- Статус: первый вариант главной страницы готов для оценки; публично не размещён
- Цель и аудитория: представить город и привлечь участников в команду политического RP.

## Контекст и решения
- Подтверждённые требования: начать с логотипа, затем собрать только главную страницу для оценки; остальные страницы делать позднее. Использовать материалы из пользовательской папки референсов.
- Контентные источники: файлы набора и ссылки на документы, два игровых скриншота города из `D:\Codex\USER_REFERENCES`.
- Принятые решения: тёмная кинематографичная подача с крупным названием, собственными скриншотами, переключением панорамы/рынка, блоками о городе, устройстве и наборе. Сайт пока статический, кнопки ведут на предоставленные Discord и документы.
- Идеи взяты из пользовательских снимков (ночной город, маяк, рынок), а также из референс-групп композиции первого экрана, типографики и тёмной стилистики. Чужие бренды и материалы не копировались.
- Ограничения: локальный предпросмотр в браузере не выполнен — политика среды заблокировала `file:` URL и запуск localhost-сервера. Скрипт визуального инспектора также не смог запустить Chrome. Линтер Taste завершился с 0 FAIL и 0 WARN.
- Неизвестное: подтвердить точное написание бренда/города и SGRB; проверить доступность и публичные права на документы/ссылку Discord перед публикацией.

## Файлы проекта
- `index.html` — главная страница.
- `styles.css` — адаптивный тёмный дизайн, анимации и состояния.
- `app.js` — переключение изображений, мобильное меню, появление секций.
- `assets/logo-concept.svg` — предыдущий редактируемый черновик знака; не подтверждён как финальный бренд.
- `assets/city-night.png`, `assets/market-street.png` — снимки, скопированные из пользовательской папки референсов.
- `.taste-skill/direction.json` — заметка о выбранном направлении дизайна.

## Текущий статус
Главная включает заставку загрузки, навигацию, большой экран с двумя переключаемыми видами города, историю команды, описание управления/законов/гражданства, ссылки на Конституцию и законы, набор по направлениям и Discord-кнопку. Это черновик для оценки, публикация не выполнялась.

## Следующие шаги
1. Пользователь открывает `index.html` локально и говорит, что сохранить или изменить.
2. После обратной связи проверить вид на телефоне в браузере и внести правки.
3. Подтвердить бренд и ссылки; затем при желании обсудить бесплатный хостинг.
